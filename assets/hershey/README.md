# Single-line pen font

`scripts.jhf` is the Hershey Script Simplex font: every letter as the pen strokes that
draw it, in the order a hand draws them. `vo_scene::stroke_write` reads it to draw words
stroke by stroke (MO-80) before they settle into the real typeface. ASCII 32 to 127, one
glyph per line in James Hurt's format.

Source: https://github.com/kamalmostafa/hershey-fonts (`hershey-fonts/scripts.jhf`).
